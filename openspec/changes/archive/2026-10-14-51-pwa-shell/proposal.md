# Proposal: 51-pwa-shell

狀態：`proposed`
編號：51。依賴 Change 50 已合入 main。

## Why
司機常在車庫、地下停車場、山區等訊號差的地方使用。目前每次開啟網站、每次點擊都要連線；訊號斷掉時只會看到瀏覽器的「無法連線」白畫面，也沒辦法像 App 一樣從主畫面一鍵開啟。

## 這次做什麼、不做什麼（請先看這段）
「離線可用」有兩個層次，這次只做第一個：

| 層次 | 內容 | 本 change |
|---|---|---|
| **A. 可安裝 + 訊號差時不白屏** | 可加到主畫面、獨立視窗開啟；離線時顯示友善的離線頁；斷線期間送出的答案在恢復連線後自動補送；畫面上明確顯示「目前離線」 | ✅ **做** |
| **B. 完全離線練習** | 把一批題目**連同正確答案**下載到手機，離線時在本機批改、之後再同步 SRS 進度 | ❌ **不做，需先由你決定**（見下） |

**為什麼 B 要另外決定**：系統目前有一條 P0 安全規則——**作答前，正確答案絕不離開伺服器**（有測試把關）。離線批改必須把答案存在手機裡，等於放寬這條規則；還會帶來「兩台裝置同時練習的進度衝突」「離線期間登入逾期」等問題，需要重新設計同步機制。這是產品與安全取捨，不該順手做掉。A 做完後再單獨提案 B。

## What Changes（A）
- **Web App Manifest**（`app/manifest.ts`）：名稱、`display: standalone`、`start_url: /`、品牌色、192／512／maskable 圖示。
- **圖示**：以品牌色產生 PNG（192、512、maskable 512、Apple touch 180），並附可重現的產生腳本。
- **Service Worker**（`public/sw.js`，不用任何套件）：
  - 頁面導覽：**先連網**；連不上才顯示預先快取的 `/offline.html`。
  - 靜態資源（`/_next/static/*`、圖示）：快取優先（檔名含雜湊，內容不變），並限制數量避免無限增長。
  - **絕不快取 `/api/*` 與已登入頁面的 HTML**：個人學習資料不留在裝置快取裡（共用手機、登出後不會殘留），也不會顯示過期資料。
  - 版本化快取名稱，啟用時清掉舊版。
- **離線頁**（`public/offline.html`）：中英雙語（依瀏覽器語言）、不依賴任何外部資源、有「重試」按鈕。
- **註冊**：只在 production 註冊；失敗靜默。
- **標頭**：`/sw.js` 設 `Cache-Control: no-cache, no-store, must-revalidate`、`Content-Type`、`nosniff`（依 Next 官方 PWA 指南），確保更新能即時生效。
- **proxy 例外**：manifest、`sw.js`、圖示、離線頁不需登入（否則未登入時被導向 `/login`，安裝與離線頁都會壞）。
- **離線提示**：畫面頂端的 `role="status"` 橫幅（i18n），斷線時顯示、恢復時消失。
- **自動補送**：練習中送答案失敗（SUBMIT_FAILED）時，裝置恢復連線就**自動重送同一份答案**（沿用既有的冪等重送，不會重複計分）。

## 風險與緩解
- **壞掉的 service worker 可能讓整站打不開**（最大風險）。緩解：只攔截明確列出的請求，其餘一律直接走網路；整個 fetch 處理包在 try/catch，出錯就放行；`/sw.js` 不快取，萬一出問題只要部署一個「自我註銷」版本即可救回（作法寫進 HANDOFF）。
- **更新延遲**：舊版 SW 可能讓用戶多看一次舊靜態檔。因靜態檔名含雜湊且頁面本身不快取，影響很小；新版 SW 採「下次載入生效」，不強制重整。
- **iOS Safari 沒有 `beforeinstallprompt`**，只能手動「加入主畫面」；本 change 不做安裝按鈕（非目標）。

## Non-goals
- B 層次的離線練習（見上）、離線同步 SRS。
- 推播通知、Background Sync API（iOS 支援不完整）、自訂安裝按鈕。
- 快取任何需要登入的資料或頁面。

## 測試（TDD）
- manifest：欄位正確、圖示檔存在且尺寸正確、品牌色一致。
- service worker：在假的 SW 環境（假 `caches`／`fetch`）測每條規則——導覽離線回離線頁、`/api` 與非 GET 不攔截、靜態檔只快取一次、HTML 不被快取、跨網域不攔截、出錯放行、舊版快取被清。
- 離線頁：雙語、無外部資源、有重試。
- proxy 例外、`/sw.js` 標頭。
- 前端：離線橫幅、恢復連線自動重送（含只重送一次）。
- **真瀏覽器**：Chromium 載入 → SW 啟用 → 切離線 → 導覽顯示離線頁 → 靜態資源離線仍可載入 → 練習中斷線送答案、恢復後自動補送成功；並確認 manifest 可被瀏覽器解析、無已登入 HTML 被快取。
- 守門三綠：`eslint` / `vitest run --fileParallelism=false` / `next build`。
